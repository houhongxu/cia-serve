开始安装 / Get started

  1. 电脑与 3DS 连接同一局域网。
    Connect your computer and 3DS to the same LAN.
  2. 在 3DS 打开 FBI → Remote Install → Scan QR Code。
    Open this menu on your 3DS.
  3. 扫描下方安装码，在 FBI 确认；每批完成后扫描下一码。
    Scan an install code and confirm in FBI. Scan the next code after each batch finishes.

保持服务运行。较密的二维码可改为单包安装。
Keep this server running. Use a single-file QR if a batch code is difficult to scan.
